# Smart City Surveillance System - AI Weapon & Anomaly Detection
Final Year Project | University of Management and Technology (UMT)

An intelligent surveillance system that transforms traditional CCTV footage into actionable intelligence using Deep Learning.

## Key Features
- AI Weapon Detection using YOLOv5
- Real-time Vehicle Traffic Density Computation
- Smart Parking Occupancy Monitoring
- Centralized Dashboard with Automated Alert Generation

## Tech Stack
Python, PyTorch, YOLOv5, MongoDB, PyQt5
 

Developed for Smart City and Cyber Security applications.
